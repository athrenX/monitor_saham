## 📖 Overview

MarketPulse AI is an AI-powered stock market analysis platform designed to help investors analyze financial markets using artificial intelligence and real-time stock data.

The platform integrates Google Gemini AI with financial data to provide intelligent market insights, interactive discussions, and investment analysis for both Indonesian and US stock markets.

This project was developed as a Software Engineering portfolio project focusing on AI integration and Financial Technology (FinTech).

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/athrenX/monitor_saham.git

cd monitor_saham
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```

Open:

```text
http://localhost:5000
```
